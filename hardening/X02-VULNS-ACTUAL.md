# X02: Vulnerability Scan — simple_ocr_capture

Run: 2026-08-20 · Derived from the X01 attack surface, by reading the code.

## Threat model

Everything this application reads is generated by a language model looking at a
screenshot. The input is therefore **arbitrary text that looks plausible** — not
random bytes, but not trustworthy either. The specific danger is not a crash; it
is a *confident wrong answer* driving an unattended run for hours.

That shapes the scan: the interesting vulnerabilities are semantic, not
memory-safety.

## `OCR_PAGE_POSITION` — parses the page indicator

| # | Vector | Assessment |
|---|---|---|
| V-01 | Integer overflow from a long digit run | **Defended.** `Maximum_digits = 9` caps the run before `to_integer`. Probe `9999999999 of 99999999999` → nothing. |
| V-02 | Position paired across two different counters | **Defended by design.** Pairs are adjacent-only, largest total wins. Probe confirms `Page 12 of 170  Location 890 of 8890` → 890 of 8890. |
| V-03 | Equal position and total rejected | **Confirmed behaviour → X03-001.** Strict `>` means the last page reads as nothing. |
| V-04 | Inverted pair (`500 of 416`) accepted | **Defended.** Same strict `>` rejects it. |
| V-05 | Zero position accepted | **Defended.** Loop requires `> 0`. |
| V-06 | Sign characters misread | **Present → X03-002.** `-5` reads as `5`. |
| V-07 | Adjacent numbers invented as a pair | **Defended.** Empty gap is deliberately not a separator. Probe `12 34` → nothing. |
| V-08 | Separator case sensitivity | **Defended.** `to_lower` before comparison; `OF` works. |
| V-09 | Stale state after a failed read | **Defended.** All fields reset at entry to `set_from`. |
| V-10 | Substring index underflow in the gap read | **Safe.** `l_ends.i_th (k) + 1 > l_starts.i_th (k+1) - 1` yields an empty string, not an error. |

## `OCR_TEXT_COMPARE` — decides whether the page turned

| # | Vector | Assessment |
|---|---|---|
| V-11 | Division by zero in `agreement_percent` | **Safe.** `l_shorter >= 1` whenever the division is reached; both-empty and one-empty are handled before it. |
| V-12 | Index underflow in `common_tail` | **Safe.** `a_limit <= l_shorter` always, because `a_limit = l_shorter - l_head` and `l_head >= 0`. Maximum index reached is 1. |
| V-13 | Head and tail double-counting the same character | **Defended.** `common_tail` is capped at `l_shorter - l_head`. |
| V-14 | Two blank reads treated as a stalled page | **Present → X03-003.** Both-empty is "same screen", so a twice-failing model stops the run blaming the page turn. |
| V-15 | `is_same_screen` disagreeing with `agreement_percent` | **Safe.** `is_same_screen` compares `(h+t)*100 >= 97*s` exactly; `agreement_percent` floors the same ratio. `floor(x) >= 97` iff `x >= 97`, so they cannot disagree. |
| V-16 | Very long or very short inputs | **Safe.** 4000-character comparison and 1-character comparison both stay in range. |

## `OCR_IMAGE_NAME` — turns model output into a file name

| # | Vector | Assessment |
|---|---|---|
| V-17 | Path separators reaching the file system | **Defended.** Whitelist `a-zA-Z0-9-`; `/` and `\` cannot survive. |
| V-18 | Reserved Windows characters | **Defended** by the same whitelist: `< > : " \| ? *` and tab all become underscores. |
| V-19 | Unbounded name length | **Defended.** `Maximum_length = 60`, enforced during construction, not after. |
| V-20 | Trailing underscore from trailing punctuation | **Defended.** Explicitly trimmed. |
| V-21 | Empty result from all-punctuation input | **Defended.** Falls back to the zero-padded counter. |
| V-22 | Counter truncation past four digits | **Safe.** `padded` pads to *at least* four; longer indices grow. |

## `OCR_IMAGE_STORE` — deletes and moves a book's images

| # | Vector | Assessment |
|---|---|---|
| V-23 | Match too broad, sweeping up the transcript | **Defended.** Whitelist on both ends: `ocr_` prefix *and* `.png`/`.bmp` suffix *and* plain file. |
| V-24 | A directory named like an image | **Defended.** `is_plain_file` guard; verified against a real `ocr_folder.png` directory. |
| V-25 | Move deleting the source on a failed copy | **Defended.** Size re-checked at the destination before `delete`. This is the highest-consequence path in the class — `copy_to` has no result. |
| V-26 | Overwriting an existing archive file | **Defended.** Collision skips and counts. |
| V-27 | Moving a folder onto itself | **Defended.** Case-insensitive equality check refuses. |
| V-28 | Drive root as output folder | **Defended.** `has_usable_leaf` refuses; otherwise `E:\D:` would be built. |
| V-29 | One locked file aborting the batch | **Defended.** Per-file rescue; verified with a real exclusive handle. |

## Out of scope

`OCR_MAIN_WINDOW`, `OCR_GUI`, `OCR_STATUS_STRIP`, `OCR_REGION_SELECTOR`,
`OCR_OUTLINE_SET`, `OCR_CAPTURE`, `OCR_CLICKER`, `OCR_HOTKEY`, `OCR_HTTP`,
`OCR_ENGINE`, `OCR_RUNTIME`, `OCR_HEALTH`, `OCR_PREFLIGHT` — all require a
screen, a Win32 call or a running OCR server. `OCR_MAIN_WINDOW` is the single
largest contract gap in the codebase (1926 lines, no invariant) and remains
unaddressed for that reason.
